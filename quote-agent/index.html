1 · Embedded widget (400px)

The quote lives in a bottom sheet because there is no room beside the chat. Tap the summary bar to expand it.

Fixed from the mockup

  • One number, everywhere. Bar, chat card and breakdown all render the same tax-inclusive total. Mockup showed $247 in the header and $262 in the breakdown of the same sheet.
  • Lines sum as printed. Each figure is rounded to cents first, then added. Mockup's $290 − $44 + $15 came to $261, not the $262 shown.
  • Discount matches its percentage. Mockup rounded $43.50 to $44, which is 15.17%.
  • Everything is priced per visit. The only unit that stays honest across one-time, weekly and monthly. A "per week" headline silently assumes a weekly cadence.
  • Cadence options come from the tenant, not a fixed list. The shipped picker renders whatever is in the frequencies collection.
  • The chat card is live, not a snapshot.

Select "2x Weekly": a live pricing bug

  • The picker advertises its configured 15%, but the wizard's freqValue() canonicalises the name to 2x-weekly, the engine's three-way === chain matches nothing, and it falls through to effFreq.oneTime. The discount is shown and never applied, on the public booking form today.
  • Open PR #407 fixes the admin drawer's version with a shared withFreqDiscount() helper. The public flow is not in that PR and should reuse the same helper.
  • Tenant frequency names are free text with no preset list and no slug, so this is ordinary config, not a contrived case.

Still blocked

  • Recurring has no series. Choose Weekly and the system creates one booking. There is no recurrence concept in the model.
  • "Quarterly deep clean — included" was dropped: compute_quote cannot substantiate a bundled recurring visit.
  • "Continue to book" oversimplifies. Approval is card-gated, but this scenario is a commercial office, the segment that pays by invoice.

2 · Desktop: summary in chat, full quote in a drawer

Same pattern as the widget, one size up. The chat carries only the live summary card and is the only thing that scrolls; “Adjust & book” slides the full breakdown in as a drawer, which then owns the scroll — never two scrollbars side by side. Inside the drawer the promise is unchanged: the price and the booking button never move. Options scroll if a tenant configures many of them, but the number you are agreeing to, and the button that commits you to it, stay put. An earlier version kept a permanent quote rail beside the chat: it doubled the scroll surfaces, and its full-height slab of #171717 — button ink in this design system — outranked the conversation, which is the actual product.
